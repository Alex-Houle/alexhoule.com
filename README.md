# README (Certified Stupid)

This website is powered by vibes, caffeine, and exactly **one** port number.

- Port situation: `package.json` says `config.port = 20002`. `npm run dev`, `npm start`, and `start.sh` all use that same one. No duplicates. No twins. No evil port clones.
- If something breaks, turn it off and on again. If that doesn’t work, blame CSS. If that doesn’t work, blame a ghost in the router.

How to run:

```bash
npm install
npm run dev
```

How to stop reading this README:

```bash
cd ..
```
